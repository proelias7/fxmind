Graph engineering for project memory.

Atomic knowledge modeling.

Code symbols, events, SQL tables and notes become individual nodes, each with its exact file and line.

Provenance and evidence validation.

A fact is saved only if its evidence exists in the source. It stays active while the SHA-256 or the evidence still matches.

Incremental indexing.

Only changed files are rescanned. Nothing runs your code, and secrets are skipped.

Retrieval on a token budget.

Terms are weighted by rarity, PT and EN synonyms match, and only the best snippets fit the budget. No match falls back to source search.

Decisions, with Jev AI

Optional. Jev helps fxmind choose: which kind of task this is, which memories matter, which tool to use, what is worth saving.
