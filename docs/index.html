Install

Needs Node.js 20.9+. Run it in your project folder, then restart your agent.

01

Run one command.

Installs memory, skills and the right pack for your project.

npx --yes github:proelias7/fxmind -y
02

Or ask your agent.

Paste this into Cursor, Claude Code or Codex and press Enter.

Install fxmind in this project: run `npx --yes github:proelias7/fxmind -y` in the project root, then tell me to restart.

Update anytime.

Your memories stay. Only fxmind's own files are refreshed.

npx --yes github:proelias7/fxmind --update -y

What changes.

Agents stop starting from zero, stop guessing, and stop stepping on each other.

◎

One memory for everyone.

What any agent learns is saved in .fxmind/memory/ and committed with your code. The whole team reuses it.

⌁

Facts with receipts.

Every memory points to the exact line of code that proves it, and drops out when that code changes.

✦

An expert for your stack.

Packs bring binding best practices — security, data, performance, accessibility, clean code.

✓

Reviewed before it's done.

Each change passes short gates and a fresh, independent reviewer. Tests and checks run for real.

⇄

Parallel agents, no collisions.

Agents claim the files they edit. Two tabs, two CLIs, two teammates — nobody overwrites anybody.

⌘

Just talk to it.

No new workflow to learn. Ask in plain language; /fxmind learn, create and audit are there when you want them.

How a change goes.

Short steps the agent runs on its own. You just see the result.

Recall

Loads the facts the team already verified.

Plan

Reuses what exists, claims the files it will touch.

Verify

Runs lint, types and tests; an independent reviewer checks the diff.

Learn

Saves what it proved, for the next agent.
